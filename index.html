THE PROJECT

A navigation layer for a galaxy of worlds.

Astronavis is an independent open-source platform for galactic cartography and stellar navigation, designed to organize worlds, sectors, coordinates and routes into a coherent exploration experience.

Built as an unofficial project inspired by the Star Wars galaxy, Astronavis brings together stellar mapping, route intelligence and navigation systems in a single evolving platform.

EXPLORE

Cartography beyond known routes.

Galactic Cartography

Astronavis is being built to represent planets, stellar locations, sectors and coordinates as an interconnected galactic map.

Route Intelligence

Navigation is more than locating a world. Astronavis aims to model routes and connections between destinations to support meaningful exploration across the galaxy.

Open Source

The Astronavis platform is developed in the open, with its source code and technical evolution available through the Astronavis GitHub organization.
